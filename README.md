# Mastering Subnetting and IP Addressing 🌐🔢

## Welcome to My Subnetting Adventure! 🚀

In this project, I dove deep into the world of subnetting—a critical skill for network design and optimization. Using a combination of theoretical knowledge and practical exercises, I learned how to divide networks into smaller subnets, calculate usable IP ranges, and determine broadcast addresses. If you’re curious about how to efficiently allocate IP addresses or want to sharpen your networking skills, this is the perfect guide for you.

---

## What Was I Doing? 🤔

This assignment was all about subnetting—breaking down larger networks into smaller, manageable subnets. I tackled several scenarios, including:
- Dividing a **Class C network** (e.g., `192.168.5.0/24`) into multiple subnets.
- Performing **Fixed-Length Subnet Masking (FLSM)** on various IP ranges.
- Calculating key subnetting parameters like:
  - Network address
  - First and last usable IP addresses
  - Broadcast address
  - Number of hosts per subnet

For each scenario, I applied formulas like `2^n` for subnets and `2^h - 2` for usable hosts, ensuring every subnet met the requirements while avoiding IP wastage.

---

## Tools Used 🔧

1. **Mathematical Formulas**: Leveraged subnetting equations to calculate subnets and hosts.
   - `2^n`: Determines the number of subnets based on borrowed bits.
   - `2^h - 2`: Calculates usable host addresses per subnet.
2. **Binary Conversion**: Translated subnet masks and IP addresses into binary to understand their structure.
3. **Increment Calculation**: Used the formula `256 - subnet mask` to determine subnet boundaries.
4. **Documentation**: Organized my findings into clear tables for easy reference.
